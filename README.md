# Sports-Collab — No-login three-AI council

Mobile-first, read-only sports research workspace. **No account or login is required** for the manual, zero-cost preview.

## Use it
1. Open the app on iPhone Safari and enter a research question.
2. Copy the independently prepared GPT, Gemini, and Llama briefs to the respective assistants.
3. Paste their actual answers back into Sports-Collab.
4. Build a local council review and verify any cited evidence, roster details, injuries, odds, and dates yourself.

The three seats are **manual**, not connected live models. Demo responses are clearly labeled placeholders. The app does not independently verify sports information, place wagers, or execute transactions.

## Security and spending
Never paste API keys into the interface. Do not expose server-side credentials to unauthenticated browser clients. Real provider calls stay disabled until separately approved, with server-side spending limits and abuse controls; no-login must not become an open paid API proxy. No production deployment is authorized by this branch.

See [no-login launch plan](docs/no-login-launch-plan.md). Authentication preparation remains isolated in a separate draft PR and is not required for this launch.

This repository is independent of ATLAS and EdgeForce.
