# Triple AI Sports Council

Mobile-first, read-only manual debate prototype. Open index.html in a browser or serve as static files. It has no API keys, backend, live odds, betting execution, or automated model calls.

Workflow: enter a research question; copy the independent prompt to Gemini, GPT and Muse; paste their answers; generate a cross-examination prompt; verify evidence externally; prepare a manual final card.

Security: never paste API keys into the interface. Future API integrations require server-side secrets, authentication, explicit spending approval and a separate deployment authorization.

This repository is intentionally independent from ATLAS and EdgeForce.
